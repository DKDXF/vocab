# 用户认证功能说明

## 📥 功能概述

VocabMaster 现已支持用户登录注册功能，采用安全的密码加密存储方案。

## 🔐 安全特性

1. **密码加密**: 使用 SHA-256 + Salt 方式加密存储密码
2. **会话管理**: 基于 Cookie 的会话管理（7天有效期）
3. **输入验证**: 用户名长度限制、密码强度要求
4. **防重放**: 每次登录生成唯一的 session token

## 📡 API 接口

### 1. 用户注册

**接口**: `POST /api/auth/register`

**请求参数**:
```json
{
  "username": "testuser",
  "password": "123456",
  "email": "test@example.com"
}
```

**返回示例**:
```json
{
  "success": true,
  "message": "注册成功",
  "username": "testuser"
}
```

**验证规则**:
- 用户名: 3-20个字符，不能重复
- 密码: 至少6个字符
- 邮箱: 可选

### 2. 用户登录

**接口**: `POST /api/auth/login`

**请求参数**:
```json
{
  "username": "testuser",
  "password": "123456"
}
```

**返回示例**:
```json
{
  "success": true,
  "message": "登录成功",
  "user_id": 1,
  "username": "testuser"
}
```

**响应头**:
- 设置 `session_token` Cookie（HttpOnly，7天过期）

### 3. 用户登出

**接口**: `POST /api/auth/logout`

**功能**: 清除会话 Cookie

### 4. 获取当前用户

**接口**: `GET /api/auth/me`

**需要**: 有效的 session_token Cookie

**返回示例**:
```json
{
  "success": true,
  "message": "已登录"
}
```

### 5. 修改密码

**接口**: `POST /api/auth/change-password`

**请求参数**:
- `old_password`: 旧密码
- `new_password`: 新密码（至少6个字符）

**需要**: 有效的 session_token Cookie

## 🌐 访问页面

- **登录/注册页面**: http://localhost:8000/login
- **主页**: http://localhost:8000/

## 💡 使用流程

### 新用户注册
1. 访问 http://localhost:8000/login
2. 点击"注册"标签
3. 填写用户名、邮箱（可选）、密码
4. 确认密码后点击"注册"
5. 注册成功后自动跳转到登录页面

### 用户登录
1. 访问 http://localhost:8000/login
2. 输入用户名和密码
3. 点击"登录"
4. 登录成功后跳转到主页

### 用户登出
目前需要清除浏览器 Cookie 或关闭浏览器

## ⚠️ 注意事项

1. **密码安全**: 
   - 密码以哈希形式存储，无法恢复
   - 忘记密码需要重新注册
   
2. **会话管理**:
   - 当前使用简单 Cookie 会话
   - 生产环境建议使用 JWT 或 Redis Session
   
3. **数据隔离**:
   - 当前所有用户共享同一词书数据
   - 后续可实现用户独立的词书和进度

## 🔧 技术实现

### 数据库表结构

```sql
CREATE TABLE users (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    username        TEXT NOT NULL UNIQUE,
    password_hash   TEXT NOT NULL,  -- 格式: salt:hash
    email           TEXT DEFAULT '',
    created_at      TEXT NOT NULL,
    last_login      TEXT DEFAULT ''
);
```

### 密码加密流程

1. 生成随机 Salt（16字节十六进制）
2. 拼接: `salt + password`
3. SHA-256 哈希计算
4. 存储格式: `salt:hashed_password`

### 密码验证流程

1. 从数据库取出 `salt:hash`
2. 分离 salt 和 hash
3. 使用相同算法计算输入密码的哈希
4. 比较两个哈希值

## 🚀 后续优化建议

1. **JWT Token**: 替换简单 Cookie，支持跨域和无状态认证
2. **邮箱验证**: 注册时发送验证邮件
3. **密码重置**: 通过邮箱找回密码
4. **OAuth 登录**: 支持 GitHub、Google 等第三方登录
5. **双因素认证**: 增加短信/邮箱验证码
6. **用户数据隔离**: 每个用户独立的词书和学习进度
7. **登录日志**: 记录登录IP、时间等信息
8. **账号锁定**: 多次失败后临时锁定账号

## 📝 测试示例

```bash
# 注册用户
curl -X POST "http://localhost:8000/api/auth/register" \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"123456","email":"test@example.com"}'

# 登录用户
curl -X POST "http://localhost:8000/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser","password":"123456"}' \
  -c cookies.txt

# 获取用户信息
curl "http://localhost:8000/api/auth/me" \
  -b cookies.txt

# 登出
curl -X POST "http://localhost:8000/api/auth/logout" \
  -b cookies.txt
```
