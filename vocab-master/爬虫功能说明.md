# 单词爬虫功能使用指南

## 📥 功能说明

单词爬虫模块可以从第三方词典网站自动抓取单词的**助记法**和**例句**信息，帮助用户更好地记忆单词。

## 🌐 支持的词典源

| 词典网站 | 用途 | 返回数据 |
|---------|------|---------|
| **mnemonicdictionary.com** ⭐ | 记忆技巧/助记法 | 结构化数据（文本+点赞数） |
| **dict.cn (海词)** | 简短释义和例句 | HTML片段解析 |
| **wordsand.cn** | 词根词缀拆解 | 表格内容 |

## 📡 API 接口

### 1. 单个单词爬取

**接口**: `POST /api/crawler/crawl`

**请求参数**:
```json
{
  "word": "abandon",
  "save_to_db": true
}
```

**返回示例**:
```json
{
  "success": true,
  "word": "abandon",
  "mnemonic": "a+band+on → 一个乐队在台上演出，但观众都离开了→放弃",
  "example_sentence": "He abandoned his car in the snow.",
  "example_translation": "他在雪地里抛弃了他的车。",
  "message": "爬取成功并已保存到数据库"
}
```

**参数说明**:
- `word`: 要查询的单词（必填）
- `save_to_db`: 是否保存到数据库（默认true）

### 2. 批量爬取

**接口**: `GET /api/crawler/batch-crawl?limit=10`

**功能**: 批量爬取当前词书中缺少助记法或例句的单词

**参数**:
- `limit`: 每次处理的单词数量（默认10个）

**返回示例**:
```json
{
  "message": "批量爬取完成",
  "processed": 10,
  "success": 8,
  "failed": 2,
  "results": [
    {
      "word": "abandon",
      "status": "success",
      "has_mnemonic": true,
      "has_example": true
    }
  ]
}
```

## 💡 使用场景

### 场景1：复习时自动补充数据

当用户复习单词时，如果数据库中没有该单词的助记法或例句，前端可以调用爬虫接口实时获取：

```javascript
// 检查是否需要爬取
if (!word.mnemonic || !word.example_sentence) {
  fetch('/api/crawler/crawl', {
    method: 'POST',
    headers: {'Content-Type': 'application/json'},
    body: JSON.stringify({
      word: word.word,
      save_to_db: true
    })
  })
  .then(r => r.json())
  .then(data => {
    if (data.success) {
      // 更新页面显示
      showMnemonic(data.mnemonic);
      showExample(data.example_sentence, data.example_translation);
    }
  });
}
```

### 场景2：批量预加载数据

在学习新词书前，可以批量爬取所有单词的助记法和例句：

```bash
# 通过API调用
curl "http://localhost:8000/api/crawler/batch-crawl?limit=50"
```

## ⚠️ 注意事项

1. **网络要求**: 需要能够访问国外网站（mnemonicdictionary.com）
2. **爬取频率**: 建议控制爬取频率，避免被目标网站封禁
3. **数据质量**: 不同词典源的数据质量可能不同，优先使用 mnemonicdictionary.com 的助记法
4. **编码问题**: dict.cn 使用 UTF-8，wordsand.cn 使用 GBK 编码
5. **超时设置**: 每个请求超时时间为10秒

## 🎯 优化建议

1. **缓存机制**: 已爬取的单词会保存到数据库，避免重复爬取
2. **优先级**: 助记词典 > 海词词典 > 词根词缀词典
3. **失败重试**: 批量爬取时会记录失败的单词，可以稍后重试
4. **人工审核**: 爬取的助记法可能需要人工筛选，选择最合适的

## 📊 数据来源说明

- **助记法**: 主要来自 mnemonicdictionary.com，按点赞数排序
- **例句**: 主要来自 dict.cn（海词词典）
- **词根分析**: 来自 wordsand.cn（暂未完全集成）

所有爬取的数据都会保存到 `words` 表的对应字段中：
- `mnemonic` - 助记法
- `example_sentence` - 英文例句
- `example_translation` - 例句翻译
